# FinLab Skill 安裝說明

這份文件提供安裝 FinLab skill 的步驟，來源為
`https://github.com/koreal6803/finlab-ai-plugin`。

## 前置需求

- 可連線到 GitHub（允許存取 `https://github.com`）。
- 具備 Python 與 `pip`。

## 安裝方式

```bash
# 以 GitHub repo 直接安裝
pip install "git+https://github.com/koreal6803/finlab-ai-plugin.git"
```

如果需要安裝到虛擬環境，請先啟用對應的 venv/conda 後再執行上述指令。

## 備註

若環境無法存取 GitHub，請先確認網路或代理設定允許該網域。
